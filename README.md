# Bitácora Espacial

Portal de noticias sobre exploración espacial y ciencia construido con React y CSS moderno.

## API utilizada

Los datos provienen de la [Spaceflight News API (v4)](https://api.spaceflightnewsapi.net/v4/docs/).

## Cómo ejecutar el proyecto localmente

1. Instala las dependencias:

```bash
npm install
```

2. Crea un archivo `.env` en la raíz del proyecto basado en `.env.example` y configura la URL de la API:

```env
VITE_API_URL=https://api.spaceflightnewsapi.net/v4
```

3. Inicia el servidor de desarrollo:

```bash
npm run dev
```
